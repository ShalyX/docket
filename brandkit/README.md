# Docket brand kit

Docket's identity is built from its settlement mechanism: a docket-shaped **D** divided into weighted ruling bands. The coral band represents the share returned when a criterion does not pass. The mark should read as a single silhouette at small sizes and as a 70/30 settlement system at larger sizes.

## Core assets

- `logo/docket-mark.svg` — primary vector mark on transparent background
- `logo/docket-lockup.svg` — horizontal mark and wordmark
- `portal/docket-portal-logo.png` — square Agent Tank upload asset, 1024×1024
- `social/docket-og.png` — Open Graph and repository social preview, 1200×630
- `social/docket-youtube-thumbnail.png` — demo thumbnail, 1280×720
- `icons/favicon.svg`, `favicon-32.png`, and `apple-touch-icon.png` — product icons
- `tokens.css` — portable brand color and typography tokens

## Visual system

The graphic language uses paper, ruled divisions, criterion weights, and exact payout ratios. Use warm paper backgrounds, dark forest settlement surfaces, coral only for returned/disputed value, and mint for verified outcomes. Avoid gradients, generic Web3 network graphics, gavels, shields, locks, coins, robot heads, and decorative AI sparkles.

## Typography

- **Fraunces** — outcome headlines and editorial emphasis
- **Manrope** — interface and explanatory copy
- **DM Mono** — case IDs, hashes, weights, network state, and evidence labels

## Clear space and minimum size

Keep clear space around the mark equal to the width of its vertical spine. Do not render the standalone mark below 20 px. Use the lockup above 120 px wide; below that size, use the mark alone.

## Color roles

| Token | Hex | Role |
| --- | --- | --- |
| Paper | `#F4F0E7` | Primary background |
| Ink | `#18231F` | Body copy and monochrome mark |
| Forest | `#1E4437` | Funded/settled surfaces |
| Mint | `#A9D7B5` | Verified and paid states |
| Coral | `#D85039` | Disputed or returned share |
| Rule | `#CFCBBE` | Docket dividers and borders |

The mark may be used in monochrome ink, reversed paper, or the primary forest/coral split. Never recolor individual bands arbitrarily.
